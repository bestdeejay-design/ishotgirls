# ART DIRECTION — ISHOTGIRLS · The Training Journal №02

Документ описывает визуальную систему сайта: палитру, типографику, сетку,
правила съёмки и промты, по которым сгенерированы все фотографии проекта.
Всё, что видно на странице, воспроизводимо из этого файла.

---

## 1. Идея

**«Протокол, а не мотивация».** Журнал о реальной тренировочной работе, а не
фитнес-медиа. Из этой идеи выведено всё: контрастный «документальный» свет,
отсутствие глянца, цифры вместо обещаний, интерфейс, который читается как
производственный документ.

| Было (v1 «Training Journal») | Стало (v2 «Concrete / Ember») |
|---|---|
| тёплая печатно-бумажная палитра, олива/хаки | холодный бетон + единственный сигнальный оранжевый |
| засечный дисплей (Fraunces/Lora) | гротеск с вариативной шириной + акцентный serif-italic |
| журнальная сетка «страницы» | промышленная 12-колоночная сетка, hairline-правила |
| статичный ростер | ростер с фильтром и раскрывающимися досье |
| внешние Google Fonts | самохостинг: 280 КБ на весь шрифтовой набор |

## 2. Дизайн-система

### 2.1 Палитра (`:root` в `index.html`)

| Токен | Dark (по умолчанию) | Light | Роль |
|---|---|---|---|
| `--bg` | `#0B0B0C` ink | `#EFECE6` bone | фон полотна |
| `--bg-2` | `#101013` | `#E6E2DA` | чередование секций |
| `--surface` | `#151519` | `#FBF9F6` | карточки, формы |
| `--fg` | `#F4F1EC` bone | `#0C0C0E` | текст |
| `--dim` | bone 66 % | ink 68 % | вторичный текст |
| `--faint` | bone 43 % | ink 48 % | подписи, служебное |
| `--accent` | `#FF5A1F` ember | `#D93B00` ember deep | акцент, ссылки, данные |
| `--line` | bone 15 % | ink 16 % | hairline-правила |

Правило: **акцент — только для смысла** (номер выпуска, метрика, текущее
состояние, действие). Никаких декоративных заливок. Все контрасты текста
проверены на WCAG AA (минимум 4.5:1; служебные подписи ≥ 4.1:1 при 10–12 px
моноширинного начертания).

### 2.2 Типографика (self-hosted, `assets/fonts/`, 280 КБ)

| Роль | Шрифт | Настройки |
|---|---|---|
| Дисплей, заголовки | **Archivo** (variable, `wght` 100–900 + `wdth` 62–125) | `wdth 104–120`, трекинг −0.02…−0.045em, uppercase |
| Акцентная фраза | **Instrument Serif** italic | вставки внутри гротеска, никогда — целые абзацы |
| Служебный, цифры, метки | **JetBrains Mono** (variable) | uppercase, трекинг 0.12–0.34em, кегль 10–12 px |

Дисплей масштабируется `clamp(2.6rem, 8.4vw, 6.4rem)`; заголовки секций —
`clamp(1.9rem, 5.2vw, 3.6rem)`. Крупный текст набирается с отрицательным
трекингом, мелкий служебный — с положительным: это создаёт «плотный/рабочий»
контраст без смены семейства.

### 2.3 Сетка и ритм

- контейнер `--max: 1440px`, отступы `--pad: clamp(18px, 4.4vw, 56px)`;
- секции `padding-block: clamp(64px, 9vw, 132px)`;
- hairline-правила `1px` на `--line` вместо «полей» и теней: страница собрана
  из горизонтальных линий, как техническая документация;
- заголовок секции — триптих `№ — заголовок — пояснение` (`.shead`), на десктопе
  пояснение уходит вправо, на мобильном — под заголовок;
- темы: dark — основная, light — «бумажный» режим; выбор пользователя
  сохраняется в `localStorage`, по умолчанию берётся системная настройка.

### 2.4 Компоненты

`.btn` (solid/ghost/block) · `.chip` (фильтр) · `.card` (ростер + `.dossier`) ·
`.col` (колонка журнала) · `.tr` (строка индекса) · `.logsheet` (страница дневника) ·
`.spec` (принцип) · `.claim` (форма) · `.serial` (шкала выпусков) · `.ticker` ·
`.field-line` (инпут с плавающей меткой) · `.receipt` (квитанция после отправки).

## 3. Фотоконтент

### 3.1 Правила съёмки (общие)

- editorial-документальный стиль, «shot on 35mm», мелкое зерно, малая ГРИП;
- **жёсткий направленный свет**: окно/один источник, глубокие чернильные тени,
  длинные резкие тени на полу — визуальная «линейка», а не мягкая студия;
- тёплый костяной свет на коже, холодные тени → совпадает с парой ink/bone на сайте;
- единственный цветовой акцент — **ember** (отблеск, оранжевый отсвет);
- девушки 26–32 лет, разные типажи, **разные лица** (менять seed, в негатив
  `identical twin, same model, repeated face`);
- собранный вид: чистые волосы, опрятная посадка одежды, спокойное лицо,
  без макияжа и ретуши. Формула: **real, but put together**;
- в негатив: `glossy, airbrushed, perfect studio skin, heavy makeup, brand logos,
  text, poster typography, neon, mirror walls, commercial fitness ad`.

### 3.3 Пример промта (обложка)

```
Vertical 4:5 editorial athletic photograph. A confident, strong woman, 29 years
old, Mediterranean type — olive skin, dark hair tied back, calm focused
expression. She stands at a loaded barbell in a raw concrete gym, mid-setup for
a deadlift, chalk on her hands, fitted charcoal training top and dark leggings.
Hard raking side light from an industrial window, deep ink-black shadows, chalk
dust in the air. Subtle ember-orange gel rim light on her shoulder. Shot on 35mm
film, fine grain, high contrast, desaturated cool shadows with warm honest skin
tones. Real, working, unglamorous: no makeup, no retouching, no brand logos.
```

Остальные кадры — та же формула с заменой `типаж + дисциплина + локация`.

### 3.4 Постобработка (ImageMagick)

```
-modulate 100,90,100  -sigmoidal-contrast 2.5,50%        # сериализация цвета
-resize WxH^ -gravity center -extent WxH                 # точный кроп блока
-quality 78–80 -define webp:method=6                     # WebP
```

Раскладка ассетов: `имя-{600|900}.webp` для карточек, `-{700|1400}` для
широких колонок, `hero-{700|1000}` для обложки. Все `<img>` имеют `width/height`,
`loading="lazy"` (кроме hero), `decoding` и `srcset/sizes`. Полный набор — 1,1 МБ.

## 4. Инструменты

| Файл | Назначение |
|---|---|
| `tools/shoot.mjs` | сборка OG-превью (1200×630), иконок и произвольных скриншотов через headless Chromium |
| `tools/og.html` | макет OG-превью из токенов системы (шрифты и hero-кадр проекта) |
| `tools/icon.html` | макет иконки: знак «I» + ember-слэш на ink |

Запуск (нужен `puppeteer-core` и любой локальный Chromium):

```bash
CHROMIUM_PATH=/path/to/chromium SITE_URL=http://localhost:8000 ROOT=$PWD \
  node tools/shoot.mjs og     # → assets/img/og-cover.jpg
CHROMIUM_PATH=... node tools/shoot.mjs icon   # → assets/apple-touch-icon.png, favicon-512.png
```
