# ISHOTGIRLS — The Training Journal · Issue №02

Статический лендинг-журнал: **«Протокол, а не мотивация»**. Шесть досье
спортсменок, четыре колонки (тренировка / питание / восстановление / дневник),
индекс экипировки, манифест и форма подписки на выпуск.

Редизайн 2026 года: новая дизайн-система «Concrete / Ember», новые шрифты
(self-hosted), новый фото-контент, адаптивная вёрстка от 320 px и полная
клавиатурная доступность. Визуальные правила и промты — в [ART_DIRECTION.md](ART_DIRECTION.md).

## Запуск

```bash
python3 server.py          # http://localhost:8000
python3 server.py 8080     # другой порт
```

Любой другой статический сервер тоже подойдёт — сборки нет, зависимостей нет.

## Структура

```
index.html                 единственная страница: разметка, дизайн-система в <style>, логика в <script>
server.py                  локальный статический сервер (кэш-заголовки, iframe разрешён)
sitemap.xml                карта сайта + image-разметка
ART_DIRECTION.md           идея, токены, типографика, правила съёмки, промты, постобработка
assets/
  fonts/                   Archivo (var wght+wdth), Instrument Serif, JetBrains Mono — 280 КБ
  img/                     WebP 600/900 + 700/1000/1400, OG-превью 1200×630 (1,1 МБ всего)
  favicon.svg              знак: «I» + ember-слэш
  apple-touch-icon.png     иконка iOS 180×180
  favicon-512.png          иконка 512×512
tools/
  shoot.mjs                сборка OG/иконок и скриншотов через headless Chromium
  og.html, icon.html       макеты растровых ассетов из токенов системы
_raw/                      исходные PNG генератора (в .gitignore, нужны только для пересборки)
```

## Возможности страницы

- **Две темы** (dark «бетон» / light «бумага»): системная по умолчанию, ручной
  выбор запоминается в `localStorage`.
- **Ростер с фильтром** по дисциплине и раскрывающимися досье (сплит, тоннаж,
  сон, недельная динамика, цитата).
- **Индекс экипировки** — таблица с оценками и правилами-хайрлайнами.
- **Шкала выпусков**, **бегущая строка метрик**, счётчики при появлении.
- **Форма подписки** с валидацией и «квитанцией» (демо: данные никуда не уходят).
- **A11y**: skip-link, `aria-expanded`/`aria-pressed`/`aria-current`, живой
  статус фильтра, фокус-стили, `prefers-reduced-motion`, скрытые заголовки.
- **Производительность**: 0 зависимостей, 0 внешних запросов, ~1,4 МБ ассетов,
  preload критичных шрифтов и обложки, `srcset/sizes`, lazy-loading.

## Адаптивность

Mobile-first от 320 px: сетка ростера `auto-fill`, колонки и таблицы
переключаются по breakpoint'ам (760 / 820 / 900 / 1000 / 1100 px), навигация
превращается в полноэкранное меню, типографика масштабируется `clamp()`.
Горизонтального скролла нет ни на одном распространённом разрешении.

## Разработка

```bash
python3 server.py                       # превью
CHROMIUM_PATH=/path/to/chromium SITE_URL=http://localhost:8000 ROOT=$PWD \
  node tools/shoot.mjs og               # пересобрать OG-превью
```

> Демо-прототип: все цифры, имена и оценки вымышлены, форма ничего не отправляет.
