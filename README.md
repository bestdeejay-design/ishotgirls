# ISHOTGIRLS — Field Notes · выпуск №01

Одностраничный сайт-«выпуск» кураторского дневника реальных тренировок.
Статика без зависимостей: один `index.html`, self-hosted шрифты, свой
фото-пайплайн на Python.

**Смысл:** «Real training, not filtered motivation» — дневник дисциплины
(тоннаж, сон, еда, стрик) вместо отфильтрованной мотивации.

---

## Быстрый старт

```bash
python3 server.py          # http://localhost:8000
python3 server.py 8080     # другой порт
PORT=8080 python3 server.py
```

Сервер раздаёт каталог, в котором лежит сам, слушает `0.0.0.0` (работает и
через внешний прокси), не ставит `X-Frame-Options`, чтобы страницу можно было
показывать во встроенном превью. Любой другой статический сервер тоже подойдёт:

```bash
python3 -m http.server 8000
```

Публикация — GitHub Pages (project site): `https://bestdeejay-design.github.io/ishotgirls/`.

## Дизайн-система Field Notes

Документальная редакционная система: строгая сетка, много воздуха, тонкие
волосяные линии, номера и подписи — монотипным шрифтом.

**Токены** (CSS-переменные в `:root`, светлая тема — `html[data-theme="light"]`):

| Роль | Тёмная тема (по умолчанию) | Светлая тема |
|---|---|---|
| фон | `--ink #0A0A09` | `--bone #F4F0E6` |
| поверхность | `--ink-2 #101010`, `--ink-3 #161614` | `#EDE7DA`, `#E4DCCB` |
| текст | `--bone #EFE9DD` | `#14140F` |
| акцент | `--olive-2 #9BAA78` | `#4F5B36` |
| линии | `color-mix(in srgb, var(--fg) 13%, transparent)` | — |

Плюс приглушённые `--tan #C3B394` и `--clay #8A6A4F` для вторичных подписей.

**Типографика** (все шрифты self-hosted в `assets/fonts`, без блокирующих
запросов к Google Fonts):

- **Instrument Serif** — заголовки и цитаты, крупный кегль, курсив как акцент;
- **Archivo** (variable, 100–900) — интерфейс, подписи, кнопки;
- **Archivo X** (variable, широкий) — вордмарк ISHOTGIRLS;
- **JetBrains Mono** (variable) — метки, индексы, цифры, «капитель» выпуска.

**Компоненты:** `.btn` (solid / ghost), `.card` + `.card--row`, `.feature`
(профиль месяца), `.col` (колонка), `.gear-row`, `.log-table`, `.chip`
(фильтры), `.phone` (макет дневника), `.ticker` (бегущая строка),
`.statement` (крупное утверждение), `.rv` (reveal-анимация с задержкой `--d`).

## Структура репозитория

```
index.html                 вся страница: разметка + CSS + JS в одном файле
server.py                  локальный сервер (0.0.0.0, без X-Frame-Options)
robots.txt, sitemap.xml     индексация
assets/fonts/*.woff2       Instrument Serif, Archivo, Archivo X, JetBrains Mono
img/                       веб-ассеты: hero, roster, columns, feature, og-image
tools/build_images.py      пайплайн: кроп → ресайз → WebP + сборка og-image.png
IMAGE_PROMPTS.md           промты всех изображений и реестр персонажей
raw/                       мастера для пайплайна (в git не попадают)
```

## Фотоматериал

Все кадры выпуска — постановочные «документальные» съёмки одного визуального
языка: утренний свет, индустриальные залы, палитра ink/olive/bone, «real, but
put together». Промты и реестр типажей — в [`IMAGE_PROMPTS.md`](IMAGE_PROMPTS.md).
Сборка веб-версий:

```bash
python3 tools/build_images.py          # мастера из ./raw → img/*.webp + og-image.png
```

Пропорции и имена зафиксированы в `MANIFEST` внутри скрипта и должны совпадать
с `index.html`.

## Доступность и производительность

- контраст текста ≥ 4.5:1 в обеих темах, фокус-стили `:focus-visible`, skip-link;
- шрифт `woff2` + `preload` для двух ключевых начертаний, `font-display: swap`;
- изображения — WebP q=80 с явными `width`/`height` (нет сдвигов вёрстки),
  `loading="lazy"` для всего, кроме обложки;
- нулевые зависимости и внешние CDN; анимации только на `transform`/`opacity`.
